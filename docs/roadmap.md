# Roadmap & Use Cases

## Future Improvements

| Improvement | Description |
|-------------|-------------|
| **Apache Iceberg** | Transactional table support for ACID guarantees on S3 |
| **CI/CD pipeline** | Automated testing and deployment on push |
| **Data quality layer** | Schema validation and anomaly detection before Gold consolidation |
| **Monitoring dashboards** | CloudWatch dashboards for job metrics, API failure rates, and latency |

## Use Cases

This dataset enables a range of sustainability and performance analyses for open ML models:

| Use Case | Description |
|----------|-------------|
| **Sustainability analysis** | Study CO2 emissions across open ML models and frameworks |
| **Emissions vs. size correlation** | Correlate CO2 footprint with model parameter count |
| **Dataset usage patterns** | Identify which datasets are most commonly used across high-emission models |
| **Metadata quality benchmarking** | Measure reporting completeness across model cards |
| **Analytical consumption** | Query the Gold layer via Amazon Athena or BI dashboards |
