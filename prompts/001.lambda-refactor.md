# Analyze existing Lambda

Analyze the selected AWS Lambda implementation and its Terraform deployment configuration.

Do not modify files yet.

## Goals

1. Find the Lambda handler configured in Terraform.
2. Identify the source file that contains the handler.
3. Identify how Terraform packages the Lambda artifact.
4. Identify all environment variables used by the Lambda.
5. Identify all AWS services or external services called by the Lambda.
6. Identify business logic currently mixed into the handler.
7. Identify data transformation logic.
8. Identify validation logic.
9. Identify logging and error handling behavior.
10. Identify risks if this Lambda is modularized.

## Constraints

- Do not edit files.
- Do not propose changing Terraform unless required.
- Do not change the handler path yet.
- Preserve the current runtime behavior.

## Output

Return:

1. Current Lambda entrypoint
2. Terraform packaging mechanism
3. Current responsibilities inside the Lambda
4. Proposed module boundaries
5. Safe first refactoring step
6. Risks and assumptions
7. Tests that should exist before refactoring
